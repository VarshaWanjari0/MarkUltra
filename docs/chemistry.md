# Chemistry

mdchemical (mhchem) is part of KaTeX, and MarkUltra ships it.

The combustion of hydrogen:

$$\ce{2H2 + O2 -> 2H2O}$$

Methane, with states:

$$\ce{CH4(g) + 2O2(g) -> CO2(g) + 2H2O(l)}$$

An equilibrium, and a concentration:

$$\ce{N2 + 3H2 <=> 2NH3} \qquad \pu{1.5e-3 M}$$

Inline chemistry works too: $\ce{H2SO4}$ is sulphuric acid and $\ce{2H2 + O2 -> 2H2O}$
is water. Isotopes and charges are ordinary mhchem: $\ce{^{14}_{6}C}$, $\ce{Fe^3+}$,
$\ce{SO4^2-}$.
